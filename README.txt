PROYEK WEBSITE PENYEWAAN MOBIL

File:
- index.html             : Beranda/Dashboard
- katalog_123.html       : Katalog Mobil
- form_sewa_123.html     : Form Penyewaan
- style.css              : Tampilan dan responsivitas
- script.js              : Validasi form

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Jalankan index.html menggunakan Live Server.
4. Uji navigasi ke katalog_123.html dan form_sewa_123.html.

PENTING:
Angka 123 hanya contoh. Ganti 123 pada nama file dan tautan HTML
dengan 3 digit terakhir NIM Anda. Ganti juga angka pada contoh harga
dan nama penyewa saat mengambil screenshot sesuai instruksi dosen.

BUKTI SCREENSHOT YANG HARUS DIAMBIL SENDIRI:
1. Network: katalog dengan Request Method GET dan Status Code 200.
2. Katalog tampilan HP (1 kolom).
3. Katalog tampilan PC/Desktop (3 kolom).
4. Form dengan nama Anda + 3 digit NIM dan hasil validasi error
   (lama sewa 0 atau kosong), atau validasi sukses pada Console.
